Acerca del proyecto

¿Qué es DBZ Chat?

DBZ Chat es una Single Page Application donde podés chatear con personajes del universo Dragon Ball Z usando inteligencia artificial. Cada personaje tiene su propia personalidad, forma de hablar y reacciones únicas — todo definido a través de un system prompt que guía a la IA para mantenerse en el rol.

¿Cómo funciona?

Elegís un personaje en la galería, escribís un mensaje y la app lo envía a una función serverless en Vercel que actúa como intermediario. Esa función llama a la IA con el historial completo de la conversación y el system prompt del personaje, y devuelve la respuesta. La API key nunca queda expuesta en el frontend.

  • Navegación SPA sin recargas usando History API
  • Historial de conversación mantenido durante la sesión
  • API key protegida mediante Vercel Serverless Functions
  • Modo oscuro y claro con persistencia en localStorage
  • Diseño responsive: mobile, tablet y desktop

Tecnologías

  • HTML, CSS y JavaScript vanilla con ES Modules
  • History API para routing SPA sin frameworks
  • Vercel Serverless Functions como proxy de la IA
  • OpenRouter — modelo google/gemini-3.1-flash-lite
  • Vitest para tests unitarios
  • DragonBall API para imágenes y datos de personajes
